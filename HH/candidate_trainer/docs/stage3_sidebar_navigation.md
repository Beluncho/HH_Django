# Этап 3: Sticky sidebar навигация

**Статус:** ✅ Выполнен  
**Дата:** 2025-01-XX

## Что реализовано

### 1. Структура страницы с sidebar

Добавлена двухколоночная layout-сетка:
- Левая колонка: sticky sidebar (240px)
- Правая колонка: основной контент

### 2. Sidebar навигация

**Элементы меню:**
- Обзор (метрики анализа)
- Навыки (с количеством)
- Собеседования (с количеством, если есть активные)
- Объяснения навыков (список с отступом)
- Вакансии

**Особенности:**
- Sticky позиционирование (top: 80px)
- Автоподсветка активной секции при скролле
- Плавный переход к секции по клику
- Счётчики (badges) для навыков и собеседований

### 3. Якоря для навигации

Добавлены `scroll-target` с ID для всех разделов:
- `#overview` — заголовок страницы
- `#skills` — таблица навыков
- `#interviews` — блок собеседований
- `#skill-{id}` — каждое объяснение навыка
- `#vacancies` — список вакансий

### 4. JavaScript для интерактивности

**Функциональность:**
- Smooth scroll при клике на ссылку
- Intersection Observer для отслеживания видимых секций
- Автоматическое добавление класса `.active` к текущей секции
- Offset для учёта высоты header (80px)

### 5. Responsive дизайн

На экранах < 992px:
- Sidebar скрывается (`display: none`)
- Layout переключается на одноколоночный
- Сохраняется вся функциональность контента

## Технические детали

### CSS переменные
Используются существующие:
- `--surface` — фон sidebar
- `--line` — границы
- `--ink` — текст
- `--muted` — второстепенный текст
- `--primary` — активная ссылка
- `--canvas` — hover фон

### Intersection Observer
```javascript
observerOptions: {
    rootMargin: '-100px 0px -66%',
    threshold: 0
}
```
Секция считается активной когда её верхняя часть находится в верхней трети экрана.
