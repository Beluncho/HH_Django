# Чеклист тестирования всех 3 этапов

## Этап 1: Управление сессиями собеседований

### Dashboard (http://localhost:8000/trainer/)
- [ ] Есть секция "Активные собеседования"
- [ ] Показывается дата и количество сообщений
- [ ] Клик по сессии ведёт на страницу собеседования

### Страница анализа
- [ ] Если есть активные сессии — показывается список с кнопками "Продолжить"
- [ ] Показывается дата создания и количество сообщений
- [ ] Кнопка "Начать новое собеседование" всегда доступна
- [ ] Клик "Продолжить" ведёт на существующую сессию

---

## Этап 2: Глобальная база объяснений

### Создание объяснения
- [ ] Нажать "Объяснить" на любом навыке
- [ ] Объяснение создаётся и отображается с markdown
- [ ] При повторном заходе на страницу анализа кнопка стала "Посмотреть"
- [ ] Якорь #skill-{id} работает (скролл к объяснению)

### Проверка глобальности
- [ ] Создать второй анализ с теми же навыками
- [ ] Объяснения должны сразу быть доступны (кнопка "Посмотреть")
- [ ] Текст объяснения тот же, что и в первом анализе

### Markdown рендеринг
- [ ] Заголовки отображаются правильно (## → h2)
- [ ] Списки форматируются
- [ ] Блоки кода в ```
- [ ] Нет видимых markdown-символов (**, ##, -, и т.д.)

---

## Этап 3: Sticky sidebar навигация

### Sidebar
- [ ] Sidebar слева прилипает при скролле
- [ ] Меню содержит: Обзор, Навыки, Собеседования (если есть), Объяснения, Вакансии
- [ ] Счётчики (badges) показывают количество

### Навигация
- [ ] Клик по ссылке плавно скроллит к секции
- [ ] Активная секция подсвечивается при скролле
- [ ] Класс `.active` добавляется автоматически

### Responsive
- [ ] На узком экране (<992px) sidebar скрывается
- [ ] Контент остаётся читабельным

---

## Дополнительные проверки

### Ошибки в консоли браузера (F12)
- [ ] Нет JavaScript ошибок
- [ ] Нет 404 на CSS/JS файлы

### Источники объяснений
- [ ] Раскрывается список источников (details/summary)
- [ ] Ссылки на вакансии работают

### База данных
- [ ] В админке видно SkillExplanation с user=NULL и is_active=True
- [ ] При создании нового объяснения старое деактивируется (is_active=False)
