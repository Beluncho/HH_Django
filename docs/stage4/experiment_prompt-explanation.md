## Навык: Python

**Назначение:**

Python — это высокоуровневый, интерпретируемый язык программирования общего назначения, который широко используется для веб-разработки (backend), анализа данных, машинного обучения, автоматизации задач и многого другого. Его синтаксис прост и читаем, что делает его отличным выбором как для начинающих, так и для опытных разработчиков.

**Ключевые понятия:**

*   **GIL (Global Interpreter Lock):** Механизм в CPython (стандартной реализации Python), который ограничивает одновременное выполнение байт-кода Python только одним потоком в одном процессе. Это влияет на производительность многопоточных приложений, но не на многопроцессные.
*   **Асинхронность (asyncio):** Позволяет выполнять несколько задач "одновременно", не блокируя основной поток выполнения. Это достигается за счет использования `async` и `await` ключевых слов, что особенно полезно для I/O-связанных операций (например, сетевые запросы, работа с базами данных).
*   **Типизация (typing):** В Python можно использовать аннотации типов для указания ожидаемых типов данных для переменных, аргументов функций и возвращаемых значений. Это помогает улучшить читаемость кода, облегчить отладку и использовать статические анализаторы кода.
*   **FastAPI/Django (DRF):** Популярные фреймворки для создания веб-сервисов и REST API на Python. FastAPI известен своей скоростью и простотой использования, особенно с Pydantic для валидации данных. Django (с Django REST framework) — более комплексный фреймворк с богатым набором инструментов.
*   **REST API:** Архитектурный стиль для проектирования сетевых приложений. REST API используют стандартные HTTP-методы (GET, POST, PUT, DELETE) для взаимодействия с ресурсами.
*   **OpenAPI/Swagger:** Спецификации для описания REST API. Они позволяют генерировать документацию, клиентские библиотеки и автоматически тестировать API.
*   **SQLAlchemy:** Мощный ORM (Object-Relational Mapper) для Python, который позволяет работать с базами данных, используя объекты Python вместо написания SQL-запросов напрямую.
*   **Alembic:** Инструмент для управления миграциями баз данных для SQLAlchemy. Позволяет отслеживать изменения схемы базы данных и применять их к различным окружениям.
*   **pytest:** Популярный фреймворк для тестирования на Python. Он предлагает простой синтаксис для написания тестов и мощные возможности для их организации и выполнения.
*   **Пирамида тестирования:** Концепция, описывающая соотношение между различными типами тестов (юнит-тесты, интеграционные тесты, end-to-end тесты). Обычно рекомендуется иметь больше юнит-тестов, чем интеграционных, и меньше end-to-end тестов.
*   **Docker:** Платформа для контейнеризации приложений. Docker позволяет упаковывать приложения и их зависимости в изолированные контейнеры, что упрощает развертывание и управление.
*   **Kubernetes:** Система оркестрации контейнеров, которая автоматизирует развертывание, масштабирование и управление контейнеризированными приложениями.
*   **Kafka/RabbitMQ:** Системы обмена сообщениями (брокеры сообщений), которые используются для асинхронного взаимодействия между различными сервисами.

**Практический пример:**

Представьте, что вы разрабатываете веб-сервис для управления списком задач. Вам нужно создать API, который позволит пользователям добавлять, получать, обновлять и удалять задачи.

1.  **Проектирование API:** Вы можете использовать FastAPI для создания API. Определите эндпоинты (например, `/tasks` для получения списка задач, `/tasks/{task_id}` для получения конкретной задачи).
2.  **Модель данных:** Используйте Pydantic для определения модели задачи (например, `Task` с полями `id`, `title`, `description`, `completed`). FastAPI автоматически использует Pydantic для валидации входящих данных и сериализации исходящих.
3.  **База данных:** Используйте SQLAlchemy для взаимодействия с PostgreSQL. Определите модель базы данных, соответствующую модели Pydantic.
4.  **Асинхронность:** Для выполнения запросов к базе данных используйте асинхронный драйвер (например, `asyncpg`) и асинхронные возможности SQLAlchemy, чтобы не блокировать API во время ожидания ответа от базы данных.
5.  **Тестирование:** Напишите юнит-тесты с помощью `pytest` для проверки логики ваших функций и интеграционные тесты для проверки взаимодействия API с базой данных.
6.  **Контейнеризация:** Упакуйте ваше приложение в Docker-контейнер, чтобы его можно было легко развернуть.

## Python

### 1. Зачем навык нужен в работе

Python — это универсальный язык программирования, который широко используется в разработке веб-сервисов, автоматизации задач, анализе данных, машинном обучении и многих других областях. В контексте вакансий, Python часто требуется для:

*   **Разработки бэкенд-сервисов:** Создание серверной части веб-приложений, API, микросервисов. Это включает в себя обработку запросов, взаимодействие с базами данных, реализацию бизнес-логики.
*   **Автоматизации процессов:** Написание скриптов для автоматизации рутинных задач, развертывания, тестирования.
*   **Работы с данными и AI:** Создание пайплайнов обработки данных, разработка AI-агентов, инференс моделей.

В целом, Python позволяет быстро создавать надежные и масштабируемые решения, что делает его востребованным навыком для разработчиков.

### 2. Ключевые понятия

*   **Python 3.11+:** Указывает на необходимость знания актуальной версии языка, которая включает новые возможности и оптимизации.
*   **GIL (Global Interpreter Lock):** Важное понятие в Python, влияющее на многопоточность. Понимание GIL помогает оптимизировать производительность многопоточных приложений.
*   **Оптимизация и профилирование:** Навыки поиска и устранения "узких мест" в коде для повышения его скорости и эффективности.
*   **Асинхронность (asyncio):** Позволяет выполнять несколько задач одновременно без блокировки основного потока выполнения, что критично для высоконагруженных сервисов.
*   **Типизация (typing):** Использование аннотаций типов для повышения читаемости кода, облегчения отладки и улучшения работы инструментов статического анализа.
*   **FastAPI / Django (DRF):** Популярные фреймворки для веб-разработки на Python. FastAPI часто упоминается в связке с Pydantic для валидации данных, а Django — с DRF (Django REST framework) для создания REST API.
*   **REST API:** Архитектурный стиль для построения веб-сервисов. Понимание принципов REST, методов HTTP (GET, POST, PUT, DELETE) и форматов данных (JSON) является фундаментальным.
*   **OpenAPI/Swagger:** Спецификации для описания REST API, которые помогают в документировании и автоматизации взаимодействия с API.
*   **SQLAlchemy:** ORM (Object-Relational Mapper) для работы с базами данных из Python. Позволяет писать запросы к БД, используя объекты Python.
*   **PostgreSQL:** Популярная реляционная база данных. Важно уметь оптимизировать SQL-запросы к ней.
*   **Alembic:** Инструмент для управления миграциями баз данных, часто используется с SQLAlchemy.
*   **Pytest:** Фреймворк для тестирования Python-кода. Важно уметь писать unit- и интеграционные тесты.
*   **Пирамида тестирования:** Концепция, описывающая соотношение различных типов тестов (unit, integration, end-to-end) для обеспечения качества продукта.
*   **Docker:** Технология контейнеризации, позволяющая упаковывать приложения со всеми зависимостями в изолированные контейнеры.
*   **Docker-compose:** Инструмент для управления многоконтейнерными Docker-приложениями.
*   **Kubernetes:** Система оркестрации контейнеров, часто упоминается как "плюс" — желательный, но не обязательный навык.
*   **Брокеры сообщений (Kafka/RabbitMQ):** Системы для асинхронного обмена сообщениями между сервисами, важны для построения распределенных систем.
*   **LLM (Large Language Models):** Большие языковые модели. В контексте Python-разработки может потребоваться опыт работы с ними через API (OpenAI API) или специализированные библиотеки (vLLM, TGI).
*   **Prompt Engineering:** Навык составления эффективных запросов (промптов) для LLM.

### 3. Практический пример

Представьте, что вам нужно разработать сервис для обработки заказов интернет-магазина.

1.  **Проектирование API:** Вы используете **FastAPI** для создания REST API. Определяете эндпоинты, например, `/orders` (POST для создания заказа, GET для получения списка заказов) и `/orders/{order_id}` (GET для получения деталей конкретного заказа, PUT для обновления статуса). Используете **Pydantic** для описания моделей данных (например, `Order` с полями `id`, `user_id`, `items`, `status`) и валидации входящих запросов. Описываете контракт API с помощью **OpenAPI/Swagger**.
2.  **База данных:** Для хранения заказов используете **PostgreSQL**. С помощью **SQLAlchemy** создаете модели, соответствующие таблицам в БД, и пишете код для сохранения и извлечения заказов. Для управления изменениями схемы БД используете **Alembic**. При необходимости оптимизируете сложные **SQL-запросы**.
3.  **Асинхронность:** Чтобы сервис оставался отзывчивым при большом количестве запросов, используете **asyncio** и асинхронные драйверы для PostgreSQL. Это позволяет обрабатывать запросы, не блокируя основной поток выполнения, например, во время ожидания ответа от внешних сервисов или БД.
4.  **Тестирование:** Пишете **unit-тесты** для отдельных функций и классов с помощью **pytest**, проверяя их корректность. Пишете **интеграционные тесты**, которые проверяют взаимодействие между разными частями сервиса (например, API и базой данных). Следуете принципам **пирамиды тестирования**.
5.  **Контейнеризация:** Упаковываете ваше приложение с зависимостями в **Docker-контейнер**. Используете **docker-compose** для настройки окружения разработки, включая базу данных и, возможно, брокер сообщений.
6.  **CI/CD:** Настраиваете конвейер непрерывной интеграции и доставки (CI/CD), который автоматически запускает тесты при каждом коммите и, возможно, развертывает новую версию приложения.
