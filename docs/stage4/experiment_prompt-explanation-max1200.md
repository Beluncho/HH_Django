## Навык: Python

**Назначение:**

Python — это высокоуровневый, интерпретируемый язык программирования общего назначения, который широко используется для веб-разработки (backend), анализа данных, машинного обучения, автоматизации задач и многого другого. Его синтаксис прост и читаем, что делает его отличным выбором как для начинающих, так и для опытных разработчиков.

**Ключевые понятия:**

*   **GIL (Global Interpreter Lock):** Механизм в CPython (стандартной реализации Python), который позволяет только одному потоку выполнять байт-код Python в любой момент времени в одном процессе. Это влияет на производительность многопоточных приложений, использующих CPU.
*   **Асинхронность (asyncio):** Позволяет выполнять задачи конкурентно, не блокируя основной поток выполнения. Это особенно полезно для I/O-bound операций (например, сетевые запросы, работа с файлами), где программа может выполнять другие задачи, пока ожидает завершения операции.
*   **Типизация (typing):** Система аннотаций типов в Python, которая позволяет указывать ожидаемые типы данных для переменных, аргументов функций и возвращаемых значений. Это помогает выявлять ошибки на этапе разработки и улучшает читаемость кода.
*   **FastAPI/Django (DRF):** Популярные фреймворки для веб-разработки на Python. FastAPI известен своей скоростью и простотой использования, особенно для создания API, благодаря интеграции с Pydantic для валидации данных. Django — более комплексный фреймворк с большим количеством встроенных инструментов.
*   **REST API:** Архитектурный стиль для проектирования сетевых приложений. REST API использует стандартные HTTP-методы (GET, POST, PUT, DELETE) для взаимодействия с ресурсами.
*   **OpenAPI/Swagger:** Спецификации для описания RESTful API. Они позволяют документировать API, генерировать клиентский код и автоматически создавать интерактивную документацию.
*   **SQLAlchemy:** Мощный SQL-инструментарий и Object-Relational Mapper (ORM) для Python. Позволяет работать с базами данных, используя объектно-ориентированный подход.
*   **PostgreSQL:** Популярная реляционная система управления базами данных (СУБД).
*   **Pytest:** Популярный фреймворк для тестирования на Python, который упрощает написание и запуск тестов.
*   **Docker:** Платформа для разработки, доставки и запуска приложений в контейнерах. Docker позволяет упаковать приложение со всеми его зависимостями в изолированную среду.
*   **Kubernetes:** Система оркестрации контейнеров, которая автоматизирует развертывание, масштабирование и управление контейнеризированными приложениями.
*   **Kafka/RabbitMQ:** Системы обмена сообщениями (брокеры сообщений), которые используются для асинхронной коммуникации между различными частями распределенных систем.

**Практический пример:**

Представьте, что вы разрабатываете веб-сервис для управления списком задач. Вам нужно создать API, который позволит пользователям добавлять, получать, обновлять и удалять задачи.

1.  **Проектирование API:** Вы можете использовать FastAPI для создания REST API. Определите эндпоинты (URL-адреса) для каждой операции, например:
    *   `POST /tasks` — для добавления новой задачи.
    *   `GET /tasks` — для получения списка всех задач.
    *   `GET /tasks/{task_id}` — для получения конкретной задачи по ID.
    *   `PUT /tasks/{task_id}` — для обновления задачи.
    *   `DELETE /tasks/{task_id}` — для удаления задачи.
2.  **Модели данных:** Используйте Pydantic (встроен в FastAPI) для определения моделей данных задач, включая поля, такие как `id`, `title`, `description`, `completed`. Pydantic также обеспечит автоматическую валидацию входящих данных.
3.  **База данных:** Используйте SQLAlchemy для взаимодействия с PostgreSQL. Определите модель данных для задач в базе данных и настройте ORM для сопоставления объектов Python с таблицами базы данных.
4.  **Асинхронность:** Для повышения производительности при работе с базой данных или внешними API используйте `asyncio` и асинхронные драйверы для PostgreSQL (например, `asyncpg`).
5.  **Тестирование:** Напишите unit- и интеграционные тесты с использованием `pytest` для проверки корректности работы вашего API и взаимодействия с базой данных.
6.  **Контейнеризация:** Упакуйте ваше приложение в Docker-контейнер, чтобы обеспечить его переносимость и простоту развертывания.

### 2) Ключевые понятия

*   **Python 3.11+:** Указывает на необходимость знания актуальной версии языка с ее особенностями и улучшениями.

*   **Асинхронность (asyncio):** Позволяет выполнять I/O-bound задачи (например, сетевые запросы, работу с файлами) более эффективно, не блокируя основной поток выполнения.
